# chrome-yt-player-script
Lightweight Chrome extension for YouTube to script interaction with the media player through DOM

![player](https://github.com/user-attachments/assets/f147184c-209e-4f24-adb9-db5c40512c83)

## How to load
1. Download or clone this repository.
2. Go to `chrome://extensions/` in the address bar.
3. In the top-right corner, toggle **Developer mode** on.
4. Click **Load unpacked** and select the downloaded folder `yt-player-script`.
